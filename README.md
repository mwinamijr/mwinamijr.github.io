# Athumani Mwinami — portfolio

Personal site of Athumani Mwinami, Founder & CEO of [TechDometz](https://techdometz.github.io/). Live at https://mwinamijr.github.io.

Built with React, TypeScript, Vite and Tailwind CSS.

```bash
npm install
npm run dev      # local preview at http://localhost:5173
npm run deploy   # build and publish to GitHub Pages (gh-pages branch)
```

## Brand colours

Orange `#F58220` · Light Blue `#75C8ED` · Deep Navy `#123B56`.
Full palette, shades and usage rules: [BRAND-COLORS.md](BRAND-COLORS.md). In code they are Tailwind colours `orange`, `lightblue` and `navy`, defined in `src/index.css`.
